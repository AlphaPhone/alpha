# Previous device Notes

## Story: Read Notes kept by an earlier installation of Alpha

> When I update Alpha on this phone, I want to read the notes and unfinished edits the earlier app
> kept here so that an update does not make that text inaccessible.

### Previous Notes reads only after a deliberate open and closes when the binding changes

The owner opens Previous notes in the Notes menu on the same Android installation. The sheet offers
the earlier saved text and unsaved edits separately. Alpha reads only the two earlier encrypted Notes
slots. It leaves both slots intact, sends no previous content to the resident agent, and never
replays an earlier edit. A failed or unreadable source is reported separately from an empty source.
Closing the sheet or changing the owner binding cancels the visible read. A later open reads again.
Older archives, recordings, and the full upgrade remain under verification.
