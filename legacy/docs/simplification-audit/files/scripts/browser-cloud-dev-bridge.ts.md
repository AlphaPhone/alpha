## Proposed end state
A `dev-server/browser-cloud/` folder of 5 modules (~380 lines total after the cli-session removal and helper
sharing), exporting the same `createBrowserCloudDevHandler` and `browserCloudDevBridge`. Quint harnesses that slice
or symbol-pin this file (`application/manifest.json` entries, `browser-cloud-request-custody*.mjs`,
`browser-google-return.mjs`) must import the handler and drive it (they can: the factory takes `request` and
`profile` injection) before the split. Host tests for this handler (`browser-cloud-dev-bridge`, `cloud-sign-in-flow`,
`cloud-email-resend`, `provider-configuration-cancellation`, `cloud-resident-authority`) consolidate into one
`test/dev-browser-cloud-bridge.test.mjs` integration file.
