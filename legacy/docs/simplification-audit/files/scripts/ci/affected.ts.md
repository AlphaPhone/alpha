## Proposed end state
- One declarative table `[{match: RegExp, lanes: Lane[]}]` + a short "root build inputs -> all" list; ~60 lines.
- Lanes: `host` (integration tests), `quint`, `lemma`, `typecheck-build-audit`, `browser`, `android`, `prepare`, `docs`. `specs/quint/**` -> quint only; `specs/lemma/**` -> lemma only; `test/browser/**` -> browser only; `android/**` -> android (+ host only for the handful of host tests that build Java); `apps/app/**` -> typecheck-build-audit, host, browser, android.
- `test/ci-affected.test.mjs` keeps a table-driven integration test of the CLI (spawn with a fake event) and drops the source-scanning part.
