## Proposed end state
Keep the file. It stays a 7-line extension of `tsconfig.json` whose only job is ES2024 `lib` for Node tooling and a
`scripts/`-only `include`. Once the `scripts/test-*` suites move to `test/` (T9) and hosted fixtures are deleted (D5),
narrow `include` to `scripts/**/*.ts`. Once upstream vendor scripts type-check under `strict`, delete
`scripts/typecheck-scripts.ts` and call `tsc -p tsconfig.scripts.json` from `package.json` directly. In this change,
the four Calendar `scripts/test-*` files listed above must go with D4 or `npm run typecheck` fails.
