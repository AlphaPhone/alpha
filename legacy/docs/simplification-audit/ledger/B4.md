# B4: Java shared helpers (stage B, new files only)

## Done

- `android/app/src/main/java/ai/alphacompute/alphaphone/AlphaUtil.java` (new; C3, R3 root package). It is a final class
  with only JDK imports, so javac host harnesses need no new Android stubs. It contains:
  - J1: `hex(byte[])`, `sha256()` (rethrows `NoSuchAlgorithmException` as `IllegalStateException`),
    `sha256Hex(byte[])`, `sha256Hex(String)` (UTF-8) and `sha256Hex(InputStream)` (64 KiB blocks).
  - J2: the regex constants `SHA256_HEX`, `OPERATION_ID`, `OPAQUE_ID`, `UUID_CANONICAL` and `OPAQUE_36`, plus null-safe
    `isSha256Hex`, `isOperationId`, `isOpaqueId`, `isUuid` and `isOpaque36` built on precompiled patterns. I added
    `isOperationId` because the code has two distinct opaque-id forms (`{1,128}` and `[A-Za-z0-9]…{0,127}`).
  - J3: `readBounded(InputStream, int limit, String tooLargeMessage)`. The message is a parameter so each site keeps
    its exception text.
  - J9: `noCache(T extends HttpURLConnection, connectMs, readMs)`. It configures a connection that is already open,
    because `HostedTransport` opens connections through a factory and several sites store the connection in a field
    first. This replaces the proposed `openNoCache(URL…)`.
  - J10: `httpStatus(int)`.
  - J4: `submit(Executor, Runnable, Runnable)`, the same body as `PluginWorkers.submit`.
  - J7: `interface Guard { void check() throws Exception; }`.
- `android/app/src/main/java/ai/alphacompute/alphaphone/Slots.java` (new; C6, J8, constants only). It holds the slot
  names used by more than one class or by the cap/policy lists: `CLOUD_PREFIX`, `CLOUD_PRODUCTION`, `CLOUD_STAGING`,
  `LOCAL_AGENT_PROVIDER`, `GMAIL_BACKGROUND`, `NATIVE_CALENDAR_SYNC`, `NATIVE_DELETE_JOURNAL`, `SMS_SEND_LEDGER`,
  `HOSTED_DIGESTS_PREFIX`, the `NOTES_*`/`NOTE_ORIGINS`/`NOTES_AUDIO_DELETIONS` names, `NOTE_AUDIO_METADATA_PREFIX`,
  `INBOX_DRAFTS_PREFIX`, and the three `…_PATTERN` hashed-slot regexes. Every value was compared byte for byte with the
  existing literals (grep inventory plus a javac check, below).
- `docs/simplification-audit/ledger/B4-migration-map.md`: every site to migrate with its replacement, null-semantics
  notes, the sites to keep local, and the pins for each group.

No existing file was edited.

## Skipped

- **AlphaPlugin base class (J4, U-L9).** Not created. `cross-file-actions.md` §4 lists Q-AND-14 ("fix LateLaunch/
  closedMessage upstream or in a local base class?") as **Open**, and §6 item 3 makes it an upstream follow-up. Q-AND-11
  (`SerialStorageTasks` ordering) is also Open.
- **SecureSlots adapter, `Slots.of(AlphaCredentialStore)` (J6).** Not created. An adapter in `Slots.java` would import
  `AlphaCredentialStore` (Android `Context`/`AtomicFile`, upstream `JsonCredentialSlots`) and the product-local
  `HostedInbox.Store`/`HostedResultNotices.Storage`/`NativeDigestSources.Storage`. Every harness that compiles a class
  using a slot constant would then need those stubs. The local interfaces also differ (`remove`, single-slot, fault
  wrapping in `HostedDelivery`), and the upstream interfaces are separate types. The clean form is
  `AlphaCredentialStore.asSlots()` (U-L10), which edits an existing class, so it is outside this unit.
- **ownerForeground / `enum Foreground` (J5) and `calendarReadWrite` (J11).** Not in `AlphaUtil`. They need
  `Activity`, `KeyguardManager`, `ContextCompat` and `Manifest`, which would force Android stubs on every harness that
  compiles `AlphaUtil`, and most callers only need the digest. The three proposed modes also don't reproduce the sites:
  - The checks mix `isKeyguardLocked`, `isDeviceLocked` and both.
  - Some sites null-check `KeyguardManager` and some don't (Gmail, HostedResults, Deletions:57).
  - Some accept dialog focus (CalendarSyncBridge:48, CalendarScopedDeletionReview:26), some need RESUMED, and some add
    the user-unlocked or assistant-surface checks.
  - Calendar sites split into read-only (`AlphaCalendarPlugin:111`, `NativeDigestHost:33,35`) and read+write
    (`CalendarSyncBridge:47,219`, `CalendarScopedDeletionReview:24`).

  The exact composable primitives are `focused(Activity)` (`a!=null&&!isFinishing&&!isDestroyed&&hasWindowFocus`),
  `deviceUnlocked(Context)` (`lock!=null&&!lock.isDeviceLocked()`), `calendarRead(Context)` and
  `calendarReadWrite(Context)`. They belong in a separate Android-aware class (U-L8 `OwnerSurface`/
  `CalendarPermissions`), created when those sites are migrated.
- **`schedulePeriodic` (J12).** Not created. `GmailDeliveryWorker` and `HostedDeliveryWorker` are not the same code:
  - The network constraint differs (`resident` → `NOT_REQUIRED` for Hosted).
  - The catch-up policy differs (`KEEP` vs `REPLACE`).
  - Only Gmail sets backoff on the catch-up request.

  A shared helper would take three behaviour flags for two callers.
- **`exceptionFamily` (J10).** Not created. The only identical copies are two in one file
  (`NativeNotificationDiagnostics`), and `AlphaLocalAgentPlugin`'s classifier writes a different vocabulary. That is a
  local merge for the file's owner.
- **Photo permission alias constants (J13).** The proposed home is `AlphaMediaConfig`, an existing file, so this is
  left to its stage C owner.
- **`release/DataIntegrityProvider` hex.** Kept: it is a separate module.

## Verification

- `javac --release 11 -Xlint:all` compiled `AlphaUtil.java`, `Slots.java` and a scratch check class from copies in the
  scratchpad, with no warnings or errors. Running the check printed `ok`. It asserts:
  - `hex`/`sha256Hex` (bytes, UTF-8 string, stream) equal the `%02x`, `BigInteger %064x` and `Character.forDigit` forms
    over 2,000 random inputs.
  - `isUuid` equals `UUID.fromString(v).toString().equals(v)` and the `(?:-…){3}` regex, including upper case, broken
    forms and `1-1-1-1-1`.
  - `isOpaque36`, `isOperationId` and `isOpaqueId` equal their `String.matches` literals, and `isSha256Hex(null)` is
    false.
  - `readBounded` throws if and only if total > limit (sizes around 8192 and 16384, limit 0), with the given message or
    `null`.
  - `httpStatus` bounds, and `submit` accept/refuse.
  - All 20 `Slots` constants equal the literal strings found in the existing Java.
- Minimum SDK: none of the new code uses Android APIs, so minSdk (29, per the `AndroidManifest.xml` comment; there is
  no app `build.gradle` in this tree) is not a constraint. Language level: plain Java 8+ syntax.
- Name clash check: there is no `import …Slots;`/`AlphaUtil` anywhere. The nested `RecordingStore.Slots` and
  `DeferredDeletionCoordinator.Slots` shadow the simple name only inside their anonymous bodies; this is noted in the
  migration map.
- Not run: Gradle (`compileDebugJavaWithJavac`), `npm run verify` and the Android build. Free disk was about 760 MB, and
  the brief forbids Gradle assemble in this stage. No callers changed, so no importer can break.
