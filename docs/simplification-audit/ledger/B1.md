## Where sites differ (variants exported or sites left out)

- UUID: five variants are real (any/`i`, lower-case any version, v4 lower, RFC v1–5 `/i`, loose 36). Each has its own
  export; no site is tightened or loosened. The loose `/i` variant (`connection-ui.tsx:1132`, dev `cloud-connection.ts:36`)
  has no export and stays local. Patterns embedded in larger regexes (prefixes, paths) stay local.
- `isAbortError`: helpers.md said detection has no differences; it does. `instanceof DOMException` (17 sites),
  `instanceof Error` (3 sites, exported as `isNamedAbortError`), duck-typed `?.name` (3 sites, left local).
- `delay`: `local-agent.ts` inline copy rejects `signal.reason || DOMException`; the helper rejects `signal.reason`.
  They differ only for a falsy abort reason; no `abort(<falsy>)` exists in `apps/app/src` (grepped). Upstream
  `abortablePause` (`calendar-availability.ts`) rejects `Error('Aborted')` and is left alone.
- `raceAbort`: only three sites have the plain skeleton; the rest have cancel side effects or other rejection values
  and stay local (listed in the map).
- `canonicalJson`: the hand-written `owner-reminder-notification-protocol.ts` serialiser differs for `undefined`,
  `toJSON` and integer-like keys; identical for the allowlisted JSON rows it hashes. The map makes switching
  conditional on confirming the bindings return decoded JSON.
- `errorCode` narrows to strings: identical for every literal-comparison site; `cloud-voice.ts:174` (copies the raw code)
  and three reply-object reads in `connection-ui.tsx` stay local.
- `deviceTimeZone` has no `'UTC'` fallback (helpers.md proposed one) so plain sites stay byte-identical; the two
  fallback sites write `deviceTimeZone()||'UTC'`.

- `oneOf` (helpers.md §1.1): no such helper exists in `cloud-protocol.ts` and no repeated caller was found; brief forbids
  an abstraction without callers.
- `withTimeout` (R7): the three timeout-only races have different timeout outcomes; left for stage C to decide.
- `parseCivilDate` and zoned civil-day helpers (R18): their real implementation is `browser/calendar-time.ts`
  (`civil`, `calendarWall`, `calendarInstant`); copying it would duplicate code and moving it is a file move (stage F).
  `browser/calendar.ts:205` zoned `civil` has one caller, so no helper.
- `lib/url.ts` (`isHttpUrl`, `domainOf`) and an email check (R5): not in this task's file list.
- `sameSession(a, b)` (R19): equality-only uses are covered by `sameJson`.
- The deletion-owner key (`'agent:'+JSON.stringify([...6 members])`, `main.tsx:102`, `browser/deletion-recovery.ts:7`):
  product format, belongs in `browser/deletion-recovery.ts`, not `lib/`.
- Moving `anyAbortSignal`'s implementation into `lib/abort.ts`: task says `abort-signal.ts` stays; `lib/abort.ts`
  re-exports it.
