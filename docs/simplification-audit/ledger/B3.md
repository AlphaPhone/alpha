## Done

- `apps/app/src/prototype/shell-types.ts` (new; C1, D3, types.md §3.2 with R5): exports `ShellState`
  (`BASE` plus `turnStatus`, which model.js reads), `ShellProps` (props model.js/dc-lite.js read), `ShellHost`
  (every non-lifecycle method of the model.js `Component` class, extending React's `Component<ShellProps, St>`),
  `ShellLifecycle`, `ShellPrototype`, `ShellComponent`, `ViewApi<St>` (the 33 members of `api(k)`),
  `ViewDefinition<St>` (every key model.js reads from a registered view: `title`, `icon`, `aliases`, `hidden`,
  `chat`, `placeholder`, `voicePhrase`, `state`, `persist`, `jumps`, `preset`, `render`, `back`, `onLeave`,
  `ongoing`, `immersive`, `badge`, `suggestions`, `reply`, `incoming`, `actions`), `ViewRegistry`, `ViewState`,
  `ViewOutput`, `RenderValues` (all `Record<string, unknown>`) and the small shapes they use (`ShellMessage`,

  `OpenViewOptions`, `ViewSetOptions`, `SwipeOptions`, `SwipeBinding`, `ShellPullContext`, `TimerId`).
  Uses upstream `ShadeSurface` and `MobileShellNavigation*` types instead of re-declaring them. No `any`.

  `ShellHost` are `expandAndroidShade` and `chatMotion`, because model.js itself reads them (found by diffing
  `this.x` reads against assignments and methods in the class body).

  calendar-approval, clock, maps-chat, maps, contacts, phone, sms, workflow, data, selection, settings,
  subview-accessibility, home-shell and browser adapters (18), plus a repo-wide count of `shell/owner/this.<model
  method>` and `api.<member>` uses outside model.js. Every model method and `api` member adapters call is
  typed; the remaining `api.*` names (`notesFolders`, `notesTrash`, `localWorkflow*`, `getLifeOps*`, …) are
  adapter extensions and stay local per R5.
- `docs/simplification-audit/ledger/B3-migration-map.md`: replacement table, rules, known gaps, two worked
  examples (notes-share-adapter, notes-folders-adapter), both compiled.

## Skipped

- `live` is not in `ShellHost` although types.md §3.2 lists it: it is set by agent-adapter.ts, not model.js,
  and the task says not to enumerate adapter fields. Readers use `ShellHost & {live?: boolean}` (migration map,
  gap 1).
- agent-adapter's widened `vset` options (`exact`, `keepSelection`) are not in `ViewSetOptions`; `vset` and
  `send` return `unknown` so adapter overrides that report a commit still type-check (gap 2, 3).
- model.d.ts is not retyped (task: do not edit existing files). Retyping it to `ShellComponent` /
  `ViewRegistry` needs `configureChatPull` / `chatPullBinding` props typed by chat-overlay-motion-adapter
  (gap 4).
- `ViewRegistry` is `Record<string, ViewDefinition>`, not `Record<AlphaView, …>` (types.md §4 row 1): model.js
  registers deferred and dev-only views (`wallet`, simulated ones) too.
