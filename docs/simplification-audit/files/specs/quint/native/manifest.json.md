## Proposed end state
- One entry per live native model, `{models}` shape shared with the other three families.
- Entry = `path`, `module`, `sources` (product paths only), `sharedSources` (upstream paths only), optional `invariants`, `temporal`, `witnesses`, `bounds`, `additionalProofInit`; `init`/`step`/`invariant` defaulted; scenarios derived from `run *Test` in the `.qnt`.
- No `symbols` text pins, no `abstractions`/`stateMapping`/`components` prose (moved into `.qnt` header comments).
- `ControllerComposition` deleted with its `.qnt`, `composition/controllers.mjs` and Calendar port (or cut to Identity+Voice); `ApplicationComposition` remains the composition proof.
- No `upstream.lock.json` / `upstream-native-sources.json` sources unless a harness hashes them, so upstream bumps stop re-verifying unrelated models.
- Expected size: roughly 1,200-1,500 lines, down from 4,462.
