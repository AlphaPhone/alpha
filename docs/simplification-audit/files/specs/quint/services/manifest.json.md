## Proposed end state
- One registry per family stays the single source of truth that `quint-lib.ts` reads; `check-traces.mjs` imports it.
- 76 or fewer entries: `CalendarLinkedSync` deleted with its harness and its `ControllerComposition` instance;
  `MapsNavigation` folded into `MapsNavigationGuidanceReadback`; `DevelopmentDigestPending` re-scoped or deleted with
  the hosted dev digest storage; `WorkflowExecution`/`…AuditAdmission` merged if the owner agrees.
- No `symbols` text pins; harnesses that need product exports import them (PORT under T10).
- `sources` lists real files only (no one-line shims, no deleted calendar stack), used for path-scoped lanes.
- Upstream-only models live in a separate lane triggered by `upstream.lock.json`.
- Prose fields describe current behaviour only; no duplicate invariant.
