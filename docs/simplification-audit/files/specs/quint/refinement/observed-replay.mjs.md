## Proposed end state
About 50 lines: `recordComparedObservation` (ordered checkpoint recording, unchanged semantics) and `observedReplay({model, run, prefix, projection, assumptions, out})`
that runs the replay inside the `AsyncLocalStorage`, checks `checkpoints > 0` and the trace count, and writes one small receipt.
No git listing, no repository-wide hashing, no snapshot store, no `captureReplayInputs`.
