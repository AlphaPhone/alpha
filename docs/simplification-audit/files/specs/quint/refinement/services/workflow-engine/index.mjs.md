## Proposed end state
About 300 lines of scenarios (they are the real content) plus a short runner: bundle the upstream engine once, run the scenarios on PGlite and hand traces to `checkTraces`. There is no hash ceremony, no duplicate prose and no child process in the test. CI runs it only in an "upstream" lane triggered by `upstream.lock.json` or harness/model changes. Owner decision: keep it here as release evidence for the pinned engine, or move model and harness into `vendor/eliza` upstream (D14 follow-up).
