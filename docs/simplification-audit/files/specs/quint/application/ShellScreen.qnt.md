## Proposed end state
Model keeps screen, voice and view-timer ownership (`VoiceNeedsLitScreen`, `VoiceTimersOwned`, `ViewTimersOwned`, `KeptShowsView`) and loses the secure-session dimension once Wallet is gone (about 15 lines fewer). Manifest pins drop `secureAdmits`. The replay test imports an extracted shell-core module instead of slicing `model.js`, and runs once (it is already not duplicated in the aggregate index). If the screen simulation becomes dev-only, the model stays as the model of that dev surface or is deleted with it.
