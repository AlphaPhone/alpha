## Proposed end state
`settings-adapter.ts` keeps only `installSettingsAdapter`: lifecycle wiring (one mount/update/unmount/openView wrapper each), one `definition.back` wrapper driven by one `PARENTS` table, and a render that composes page builders imported from `prototype/settings/` (`notifications-page.ts`, `agent-connection-page.ts`, `licenses.ts`, `calendar-page.ts`, `password-page.ts`, `rows.ts`). App-update policy + storage move to `runtime/app-update.ts`; appearance storage to `runtime/appearance.ts`; diagnostics assembly to `runtime/diagnostics-export.ts`; browser-store recovery to a dev module. Deleted: `note`, `day`/cloud-plan page, Privacy & data branch + `voicePrivacyRow`, first `back` wrap, second `componentDidUpdate` wrap, `installedRows`, `browserDevProfile` alias, and (after probe) the Models page. Estimated: ~65 lines deleted outright, ~450 lines moved; file after ≈ 750 lines at current density (≈ 450 once page builders move).
