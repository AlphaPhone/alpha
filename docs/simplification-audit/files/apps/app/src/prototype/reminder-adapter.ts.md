## Proposed end state
`installReminderAdapter` keeps: shell wrappers for tap/visit tracking, `checkReminderTap`, `refreshReminders`, mount/unmount, and the calendar render decorator. The render decorator calls a single `runReminderOperation` for edit/done/snooze/reopen (and its finally logic for delete), `sha256Hex` and `pendingFor` from shared modules, locale-time formatting, direct calls to always-installed shell methods, one counter source. Typed with shell types. Estimated ~400 lines (from 497). Later it moves to `views/calendar/` beside the other calendar decorators.
