## Proposed end state
A `runtime/digests/` folder replaces this file: a ~90-line panel shell plus hooks and form components (~620 lines total after Prettier-equivalent density). Deleted: dev storage/recovery/scheduler branches (moved to one `browser/` dev factory), the `cloud` runtime read, the optional-method guards, the hand-rolled focus trap (now `createInlineModal`), duplicate toggle JSX, per-file style constants (CSS), the `Pending.phase` optional legacy, issue-number comments. Remains: all user copy, `aria-*` attributes, slot names `hosted-digests:v1:<hash>` / `renderer-…:pending`, polling cadence (15 s / 60 s closed), single-flight refresh, and review→dispatched journal semantics. Estimated ~720 lines across the folder (from 870).
