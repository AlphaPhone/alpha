## Proposed end state
Three files. `runtime/local-agent.ts` (~330 lines): native bridge over a fully typed `AgentPlugin`, `LocalAgentProtocol` (connect/request/conversations/send/abortTurn/subscriptions) with one `assertCurrent` and shared abort helpers, status reads, stop/await-stopped, recovery review/archive. `runtime/provider-keys.ts` (~150): provider types, labels, parsers and one `providerOperation` driving configure/select/edit/remove/reveal/clear/bind. `browser/development-agent-bridge.ts` + `browser/agent-speech.ts` (~170 moved): dev HTTP/WS bridge and browser speech. Deleted: ~25 version guards, test-only exports and seams, `recoveries`, duplicated byte helpers. Net ≈ −120 lines.
