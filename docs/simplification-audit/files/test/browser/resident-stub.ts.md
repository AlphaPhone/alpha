## Proposed end state
`resident-stub.ts` disappears. `harness/plugins/agent.ts` is the one resident-agent model. It holds conversations, history,
stream modes (`reject|busy|expired|drop|hold|failure`), held chunks, start rejection and the abort route, and it is merged
with `helpers/resident-agent-plugin.ts`. `harness/plugins/cloud.ts` holds accounts, `billing/limits`, redeem, revoke and
Google accounts. `harness/plugins/maps.ts` holds the Cloud Maps routes. `harness/signin.ts` exports
`enterNativeEmailCode(page, email)`. State is typed and read through accessors. The live Quint composition harnesses
import the new paths.
