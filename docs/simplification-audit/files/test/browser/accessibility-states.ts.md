## Proposed end state
`harness/states.ts` holds the `State` type and five lists built from one `state(kind, steps, shows)` constructor. The live,
mock and launcher variants differ only in their boot fixture (`app({connection:'offline'})`, `app({mode:'mock', start})`,
`app({bridge:'launcher'})`). Connected states use a boundary fixture in place of in-page monkey-patching. Legacy-notes states
are gone. `setTextScale` lives in `harness/text-scale.ts`. Expected size is about 300 lines.
