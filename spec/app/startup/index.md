# Startup

How Alpha comes up on the phone: walking the owner through Android's
permissions, finishing setup, and recovering when a page fails to start or
loses its process.

- [Access](./access.md): walking through Android's permissions in order, saving progress, and reviewing them from Settings
- [Steps](./steps.md): the permissions the walkthrough asks for and how each one reads
- [Finish](./finish.md): the "All set" screen after setup completes for a new account
- [Recovery](./recovery.md): showing a failure screen, flushing drafts, reloading, and switching Home when a page fails
