# Alpha

Alpha is a personal agent phone. Its owner opens Home, the built-in apps
and Ask Alpha; a resident agent on the phone plans, calls tools, remembers
and schedules, and asks before it does anything that matters. A cloud
account supplies model inference, speech, Gmail and optional Google
Calendar and Maps, and never hosts the agent.

- [Kit](./kit/): rules several areas keep
